# Email Design System - DivorceConnect India

## Color Palette (Professional Black/White/Gray)
- Primary Black: #1a1a1a
- Secondary Black: #2a2a2a
- White: #ffffff
- Light Gray: #f8f9fa, #f3f4f6
- Medium Gray: #d1d5db, #e5e7eb
- Dark Gray: #6b7280, #9ca3af

## Typography
- Font Family: Poppins (Modern, clean, professional)
- Headers: Font-size 22-24px, Weight 700
- Body: Font-size 14px, Weight 500
- Labels: Font-size 11-12px, Weight 600, Uppercase

- Modern, minimalist layout
- Color-coded status indicators (green for approved, orange for warning, red for critical)

- Clear typography hierarchy
- Responsive design for all email clients
- Action-oriented CTAs
- Security badges and encryption notices
- Professional footer with links
